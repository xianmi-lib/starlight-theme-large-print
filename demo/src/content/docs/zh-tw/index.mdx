## 主題特色

<CardGrid stagger>
	<Card title="大號襯線正文" icon="pencil">
		默認 17px 正文、1.85 倍行高，配舒適的襯線字體——長時間閱讀也不累眼。
	</Card>
	<Card title="讀者字號調節" icon="setting">
		頁首的字號下拉菜單提供五檔字號（14–22px），選擇會被記住。現在就到頁首試試。
	</Card>
	<Card title="暖色暗色模式" icon="moon">
		暗色主題採用紙張般的暖棕色，而非冷調藍黑。切換主題圖標，親手感受差異。
	</Card>
	<Card title="自託管中文字體" icon="translate">
		可選 Noto Serif 簡/繁字體包，從你自己的站點經 `unicode-range` 分包加載——訪客只下載當前頁面需要的部分。見<a href={`${import.meta.env.BASE_URL.replace(/\/$/, '')}/zh-tw/cjk/`}>中文排版</a>。
	</Card>
</CardGrid>
