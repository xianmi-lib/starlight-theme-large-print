## 主题特色

<CardGrid stagger>
	<Card title="大号衬线正文" icon="pencil">
		默认 17px 正文、1.85 倍行高，配舒适的衬线字体——长时间阅读也不累眼。
	</Card>
	<Card title="读者字号调节" icon="setting">

	</Card>
	<Card title="自托管中文字体" icon="translate">
		可选 Noto Serif 简/繁字体包，从你自己的站点经 `unicode-range` 分包加载——访客只下载当前页面需要的部分。见<a href={`${import.meta.env.BASE_URL.replace(/\/$/, '')}/zh-cn/cjk/`}>中文排版</a>。
