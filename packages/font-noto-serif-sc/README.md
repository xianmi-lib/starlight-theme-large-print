# starlight-theme-large-print-font-noto-serif-sc

Self-hosted **Noto Serif SC** (Simplified Chinese) webfont pack for [`starlight-theme-large-print`](https://www.npmjs.com/package/starlight-theme-large-print). Google Fonts' `unicode-range` woff2 subsets (~11.5 MB, 202 subsets) served from your own site — visitors only download the handful of subsets their page actually uses (typically < 200 KB), and it works where Google Fonts is blocked.

Install together with the theme and enable it in the plugin options (`font: 'noto-serif-sc'`):

```bash
npm install starlight-theme-large-print starlight-theme-large-print-font-noto-serif-sc
```

For Traditional Chinese pages use [`starlight-theme-large-print-font-noto-serif-tc`](https://www.npmjs.com/package/starlight-theme-large-print-font-noto-serif-tc) instead.

Born from [显密文库 xianmi.co](https://www.xianmi.co/), a large-scale Chinese digital library for elderly readers of classical texts.
